# The core's API reference

`@gs1-label-studio/core` (`packages/core`) holds every GS1 rule, encoder and exporter of the studio, with no user interface: the web application is one of its users, and a command line or an HTTP API could be others ([ADR 0001](adr/0001-browser-first-architecture.md)). It runs in the browser, in Web Workers and in Node 22.

This reference lists the 301 names `packages/core/src/index.ts` exports, module by module, each with its declaration and the comment above it in the source. It is generated by `node scripts/api-reference.mjs`, and a test fails when it differs from the sources ([ADR 0005](adr/0005-documentation-and-feature-inventory.md)): do not edit it by hand. How the modules fit together: the [developer guide](developer-guide.md).

The package is not published to npm yet; inside the repository it is imported as `@gs1-label-studio/core`:

```ts
import { syntaxEngine, labelFor, labelSvg, labelPdf } from "@gs1-label-studio/core";
```

## dots.ts

The printer's dot grid: X-dimensions as whole numbers of dots.

> Thermal and thermal transfer printers print on a grid of dots (203, 300 or 600 dpi; some 152 or 406). A module must be a whole number of dots, or the printer rounds each bar and space differently and the symbol's bar widths drift. So a printer output never prints the X-dimension asked: it prints the nearest whole number of dots, and the studio shows the X-dimension actually printed and checks it against the range of the application's symbol specification table (GS1 General Specifications, section 5.12.3).

## guide.ts

The decision tree of figure 5-68, section 2's carriers and the recommendation.

> The guided choice (ADR 0003, principle 1): what is identified and how it is scanned → the GS1 General Specifications' decision tree (release 26.0, figure 5-68) → a symbol specification table → the symbols it allows, and the one recommended for the data. The tree's sixteen questions keep their numbers. Three are answered by the key: 1 (GDTI, GRAI, GIAI or GLN), 4 (GSRN) and 11 (a logistic unit: SSCC, GINC or GSIN); for those logistic keys, the trade item questions 5 and 7 are answered no (section 2.7, table 2-37: logistic units have tables 5 and 12 only). Table 12 has three parts; the key chooses between them, or one more question for a GTIN (a unit pack or a grouping of packs). Each leaf of the tree is an application of section 2, whose carrier choices name the symbols in the order the recommendation follows: the first one the studio draws that carries everything identified. Where only symbols that carry the GTIN alone are allowed (EAN/UPC at a point of sale), a 2D symbol "in addition" carries the rest.

|---|---|---|---|
| `carries` | function | `function carries(symbol: SpecSymbol, input: ParsedInput, leaf?: Leaf): { carries: Carries; reason?: string }` | Whether a symbol carries all that is identified, the GTIN alone, or nothing of it; and why not, when not.
